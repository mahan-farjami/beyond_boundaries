STUDY GUIDES — VOL. 16 · CALCULUS

The Complete Integration Guide (Every Technique, Explained)

Six techniques cover almost every integral you'll ever be asked to solve. This guide walks through each one — when to use it, how it works, and a fully worked example — plus a reference table of common integrals at the end.

22 MIN READ·UPDATED 2026·CALCULUS I & II

Integration is the one part of calculus that doesn't feel like a clean algorithm — differentiation has a fixed set of rules that always work, but integration often feels like trial and error. That feeling is misleading. In reality, the vast majority of integrals you'll encounter in a standard calculus course fall into one of six categories, and each category has a specific, learnable technique attached to it.

This guide covers all six, in the order you'd actually want to try them: basic rules first, then substitution, then the more specialized techniques for products, trig functions, square roots, and rational functions. Work through them in order and you'll be able to recognize which technique a new integral needs almost on sight.

01 — FOUNDATIONS

The Power Rule and Basic Integrals

Every integration technique eventually reduces a hard integral down to something simple enough for the power rule to finish off. It's worth having it memorized cold.

POWER RULE
∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C   (n ≠ −1)

The "+ C" matters — it's not decoration. A derivative erases constants, so when you reverse the process, any constant could have been there originally. Dropping the +C is the single most common way students lose easy points on exams.

Watch for: when n = −1, the power rule breaks (you'd divide by zero). That case has its own rule: ∫ x⁻¹ dx = ln|x| + C.
WORKED EXAMPLE
1
Find ∫ (3x⁴ − 2x + 5) dx
2
Integrate term by term, applying the power rule to each: 3x⁵/5 − 2x²/2 + 5x
3
Simplify and add the constant: (3/5)x⁵ − x² + 5x + C
02 — MOST COMMON TECHNIQUE

U-Substitution

U-substitution is integration's version of the chain rule in reverse. It's the first technique to try on almost any integral that isn't immediately obvious, because it's the one that applies most often.

CORE IDEA
If u = g(x), then ∫ f(g(x))·g′(x) dx = ∫ f(u) du
Watch for: an integral containing a function and something that looks suspiciously like its derivative sitting right next to it. That's the signal to try substitution.
WORKED EXAMPLE
1
Find ∫ 2x·cos(x²) dx
2
Let u = x², so du = 2x dx — which is exactly the other factor sitting in the integral
3
Rewrite entirely in terms of u: ∫ cos(u) du = sin(u) + C
4
Substitute back: sin(x²) + C

03 — FOR PRODUCTS OF FUNCTIONS

Integration by Parts

When substitution doesn't work — usually because the integral is a product of two unrelated types of functions, like a polynomial times an exponential, or a polynomial times a trig function — integration by parts is almost always the next thing to try.

FORMULA
∫ u dv = uv − ∫ v du
Choosing u: the acronym LIATE (Logarithmic, Inverse trig, Algebraic, Trigonometric, Exponential) ranks which type of function to pick as u, in that priority order. Whichever function type appears earliest in LIATE, choose that one as u.
WORKED EXAMPLE
1
Find ∫ x·eˣ dx
2
By LIATE, x is Algebraic and eˣ is Exponential — Algebraic comes first, so u = x, dv = eˣ dx
3
Then du = dx and v = eˣ
4
Apply the formula: x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C
04 — POWERS OF SIN AND COS

Trigonometric Integrals

Integrals involving powers of sine and cosine multiplied together — like ∫ sin³(x)cos²(x) dx — need identities before they need any of the techniques above. The strategy depends on whether the powers are odd or even.

KEY IDENTITIES
sin²(x) + cos²(x) = 1
sin²(x) = (1 − cos 2x)/2
cos²(x) = (1 + cos 2x)/2
Rule of thumb: if either sin or cos has an odd power, peel off one factor, convert the rest using the Pythagorean identity, and substitute. If both powers are even, use the half-angle identities to reduce the powers first.
WORKED EXAMPLE
1
Find ∫ sin³(x) dx
2
Odd power — peel off one sin(x): ∫ sin²(x)·sin(x) dx
3
Convert using sin²(x) = 1 − cos²(x): ∫ (1 − cos²(x))·sin(x) dx
4
Substitute u = cos(x), du = −sin(x) dx: −∫(1 − u²) du = −u + u³/3 + C
5
Back-substitute: −cos(x) + cos³(x)/3 + C
05 — FOR SQUARE ROOTS OF QUADRATICS

Trigonometric Substitution

When an integral contains an expression like √(a² − x²), √(a² + x²), or √(x² − a²), regular substitution won't get rid of the square root. Trig substitution replaces x with a trig function specifically chosen so the Pythagorean identity collapses the square root cleanly.

EXPRESSION IN THE INTEGRALSUBSTITUTEIDENTITY USED
√(a² − x²)x = a sin θ1 − sin²θ = cos²θ
√(a² + x²)x = a tan θ1 + tan²θ = sec²θ
√(x² − a²)x = a sec θsec²θ − 1 = tan²θ
WORKED EXAMPLE
1
Find ∫ dx / √(4 − x²)
2
Matches the √(a² − x²) case with a = 2, so let x = 2 sin θ, dx = 2 cos θ dθ
3
Then √(4 − x²) becomes √(4 − 4sin²θ) = 2cos θ, so the integral becomes ∫ (2 cos θ dθ) / (2 cos θ) = ∫ dθ = θ + C
4
Convert back using x = 2 sin θ → θ = arcsin(x/2): arcsin(x/2) + C
After integrating: draw a right triangle labeled with the substitution to convert any leftover trig functions (like sec θ or tan θ) back into expressions of x — this step trips up more students than the integration itself.

06 — FOR RATIONAL FUNCTIONS

Partial Fractions

When you're integrating a fraction where both the top and bottom are polynomials, and the denominator factors into simpler pieces, partial fractions breaks the single complicated fraction into a sum of simple ones that are each easy to integrate on their own.

CORE IDEA
P(x) / [(x−a)(x−b)] = A/(x−a) + B/(x−b)
WORKED EXAMPLE
1
Find ∫ 1 / (x² − 1) dx
2
Factor the denominator: x² − 1 = (x−1)(x+1)
3
Split into partial fractions: 1/(x²−1) = A/(x−1) + B/(x+1), solving gives A = 1/2, B = −1/2
4
Integrate each simple term separately: (1/2)ln|x−1| − (1/2)ln|x+1| + C
Watch for: before splitting into partial fractions, the degree of the numerator must be less than the degree of the denominator. If it isn't, do polynomial long division first.
